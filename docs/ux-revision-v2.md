# UI/UX 修訂 v2 — 2026-11-05

## 使用者決定

原先三個長區塊並排導覽與重複問句造成混亂。本輪只給一版更清楚的 UI，之後再討論。整體定位、三層架構、三個模組角色與資料均不改；不接全量、不 matching、不增加功能。

## 改動

- 領域頁改成企業問題／新創參考／能力構想三個真正分頁，每次只渲染一種內容，預設企業問題。
- 分頁上方只保留領域與切換選單；移除重複編號、大問句與長介紹。
- 清單統一為名稱、簡介、詳情，移除卡片內重複模組標籤。
- 資料口徑收在「關於這些展示內容」，不反覆佔主畫面。
- 領域頁不再重複方案示範介紹；整體概念仍在首頁，方案架構仍由主導覽進入。
- 詳情底部改成明確的返回原分頁與同領域其他分頁入口，移除大型重複關係區。

## 導覽與相容

URL 新增 tab=problems／startups／capabilities。語言切換、重新整理、分享與瀏覽器返回維持分頁。每個領域／分頁分開保存捲動位置；從詳情返回恢復位置與焦點。切換領域保留目前內容種類。

舊詳情連結由 kind 推導返回分頁；舊 #problems／#startups／#capabilities 領域連結可以轉成對應分頁。使用 role=tablist／tab／tabpanel、aria-selected 及方向鍵／Home／End 操作；頁面只有一個可見 tabpanel。
