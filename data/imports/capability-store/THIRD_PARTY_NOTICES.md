Fixed source commits, file digests and observation dates are in data/raw/snapshots/*/manifest.json. Selected resource descriptions include original English list descriptions and Chinese summaries with exact list provenance. A list's license does not establish the license of each linked resource; individual resource licenses remain null until checked.

GitHub Trending is an observed weekly-page snapshot, not a recommendation or proof of use. Its original source URL and observation time are preserved separately. HTTP session-cookie headers are excluded from the published snapshot metadata.
